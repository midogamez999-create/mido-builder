# Mido Builder

A phone-first visual app builder made by Mido.

## Features

- Create projects
- Save projects in the browser
- Add components
- Responsive mobile interface
- Project dashboard
- Settings
- Browser-based
- Lightweight and fast

## Components

Current components:

- Button
- Text
- Image
- Card

## Tech

Mido Builder currently uses:

- HTML
- CSS
- JavaScript
- LocalStorage

No backend is required for the current version.
